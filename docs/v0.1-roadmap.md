## Milestone 2 — Sheet classification
Classify:

- general notes
- overall plan
- gravity sewer plan/profile

- lift station electrical

Extract:

- force main size, material, length

## Milestone 4 — Reconciliation
- compare station-derived lengths with callouts
- merge duplicate infrastructure references
- expose conflicts and confidence
- reviewer corrections

- stable JSON schema
- inventory CSV
- QA/QC integration mapping

Engineering review rules begin after the project inventory can be reproduced reliably from representative drawing sets.
